# FManager (Simple file manager)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Gestor de ficheros sencillo para Laravel y para el panel de [LaraFlex](https://github.com/caimari/laraflex).

## Requisitos

| | Versión |
|---|---|
| PHP | 7.4 o superior, incluido PHP 8.x |
| Laravel | **8.x** (`illuminate/support ^8.0`) |

## Instalación

En la raíz de tu proyecto Laravel:

```bash
composer require caimari/fmanager
```

El paquete se registra solo mediante el descubrimiento de paquetes de Laravel y carga sus propias rutas.
